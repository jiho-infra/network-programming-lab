# 01. Python TCP 소켓 프로그래밍 및 동시성 제어

파이썬 기본 내장 모듈(`socket`, `threading`, `queue`)만을 사용하여 1:1 단발성 통신부터 멀티스레드 동시성 제어, Queue 기반 최적화 서버로 단계별 고도화한 실습 프로젝트입니다.

---

## 📁 파일 목록 및 발전 단계

### 1단계: 단발성 1:1 에코 통신
* `server1.py`, `client1.py`: `accept()`를 통한 리스닝(문지기) 소켓과 통신(상담원, `conn`) 소켓 분리 및 1회 통신 후 종료

### 2단계: 연속 1:1 통신 및 세션 유지
* `server2.py`, `client2.py`, `client3.py`: `while True` 루프와 `if not data:` 예외 처리를 통한 핑퐁 대화
* `server3.py`: `accept()` 루프 중첩을 통해 클라이언트 퇴장 후에도 다음 접속을 연속 대기

### 3단계: 멀티스레딩 기반 다자간 채팅
* `client4.py`: 수신 전담 데몬 스레드를 분리하여 송/수신 입력 블로킹 완전 해결
* `server4.py`: 접속자당 1개의 `handle` 스레드를 할당하여 다자간 브로드캐스트 지원

### 4단계: Queue 도입 및 스레드 충돌 방지
* `Q.py`: 공유 자원 접근 시 발생하는 Race Condition을 방지하기 위해 Producer-Consumer 패턴 적용 (큐 삽입 전담 + 브로드캐스트 발송 전담 스레드 분리)
